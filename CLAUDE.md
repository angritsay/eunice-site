# Working on the Eunice site

Plain HTML generated by `apps/web/build.ts` (TypeScript, run directly by Node) from `apps/web/src/`. The pages we ship keep **zero runtime JavaScript dependencies** — no framework, no bundle, only our own `site.js`. Tooling and services may use packages under the supply-chain controls in [ADR-0002](docs/adr/0002-dependencies-under-supply-chain-controls.md): exact pins, a committed lockfile, a release quarantine, and a reason in the PR that adds one.

## How to make a change

1. Content that appears on more than one page (people, insights, events, quotes, roles, partners) lives only in `apps/web/src/content/index.ts`. Never paste it into a page.
2. Page copy lives in `apps/web/src/pages/<page>.ts`. Shared blocks live in `apps/web/src/components.ts`; reuse them before writing new markup.
3. Markup is written only with the `html` tag from `apps/web/src/lib/html.ts`: everything interpolated into it is escaped unless it is itself markup. `raw()` is for our own artwork (SVG paths), never for content. Content is checked against `apps/web/src/content/schema.ts` when the site builds; a new kind of content gets a schema there.
4. Run `pnpm build` and `pnpm test:web`, and make sure both pass. If you changed rendered HTML on purpose, run `pnpm test:web:update` and check the golden diff reads the way you meant. Add a new page to `apps/web/test/web/urls.json` in the same change.
5. Open a pull request with a one-line summary per change. Do not push to `main` directly.
6. A significant decision gets a record in `docs/adr/` in the same pull request.

## Design rules (agreed with the team, Sep 2026)

- White ground only. The one grey is `--band` (cool, very light). A coloured tint never sits on a grey band. No dark sections except the closing call-to-action.
- The master brand is black. Colour belongs to a desk: Private Markets = ultramarine (`--pm-*`), Digital Assets = orange (`--da-*`), Token Disclosure = gold (`--td-*`). Use the `-ink` value for text, `-field` for fills, `-tint` for image plates.
- Four type roles: `.h1`, `.h2`, body (`.body`, `.lead`, `.small`), caption (`.caption`, `.label`). No new sizes, no sub-headings.
- The scale went down 20% in September 2026, to leave more air around the type. Spacing did not move, so the gaps read wider. This put body copy at 13.6px and `.small` at 12px, under the 15px floor the team agreed earlier that year — the floor was dropped deliberately, not overlooked. Do not take it lower without asking.
- Separate things with a hairline rule on top, not with boxes, borders or shadows. No bordered cards.
- Product imagery is a real screenshot on a tinted plate (`plate()` in `components.ts`). No illustrations, no generated shapes.
- Navigation depends on the destination: company pages show the products; each product page shows its own audiences (`apps/web/src/site.config.ts`).
- Private Markets is about operational due diligence, portfolio monitoring and the end-to-end service. Regulation and the FCA sandbox belong to Digital Assets only. Trust markers on Private Markets: SOC 2 Type II, GDPR, no training on client data.
- Calls to action say "Talk to us". No "Book a demo".
- Long-form copy imported from the live site (job descriptions, and later blog posts) lives as HTML fragments in `apps/web/src/content/{jobs,posts}/`, written by `pnpm --filter @eunice/web import:live jobs|posts`. Never hand-write markup there: re-import instead. Fragments reach a page only through `richText()` (`src/lib/rich-text.ts`), which fails the build on any tag, attribute, link or image outside its allowlist.
- Exception: pages ported from the live eunice.ai site (`mica-whitepaper.ts`, `security.ts`) keep the live copy word for word, CTA labels included, and the live look (the `.mica-*` / `.sec-*` styles). Do not edit their copy or bring them under the rules above unless the owner asks.

## Copy

- Write like the desk talks to a client: plain, specific, no hype words ("revolutionary", "unlock", "game-changing").
- Judge a line by what it tells the reader, not by its length. Cut a line that carries nothing.
