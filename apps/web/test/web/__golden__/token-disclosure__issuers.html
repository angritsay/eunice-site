What this looks like now

The week we hear described most often.

  • The paper has to be right before it is filed, and there is no second first submission.
  • Every exchange that might list the token asks for the same document a different way.
  • A disclosure that was true at filing quietly stops being true.

What Eunice does

Three things, in the order they happen.

  1. Drafted from the library A MiCA white paper drafted from 1,000+ pre-filled papers, so the starting point is a document that has already been through this.
  2. Reviewed where it counts CMS reviews the points that need a legal opinion, rather than a legal bill for the whole document.
  3. Notified and hosted Notified to the authority and hosted on a public page, so there is one address for the version that stands.
